# Steady Week

A mobile-first, local-first habit, schedule and finance tracker.

## Features
- Today checklist, daily mood check-in and habit sessions
- Weekly targets, progress percentage, all-time and monthly session counts
- Three manual modes: Vacation, Sembreak, Regular Classes
- Editable day plans and school routine notes
- Income, expenses, categories, monthly budget and spending breakdown
- Weekly reflection
- JSON backup/import and a text report you can paste into ChatGPT
- Light/dark theme and installable PWA shell

## Install on Android
1. Upload the contents of this folder to a static HTTPS host such as GitHub Pages.
2. Open the HTTPS site in Chrome.
3. Open Chrome's menu and choose Install app or Add to Home screen.

## Data and privacy
Your records are stored in this browser on this device. No account or bank connection is used. Export a JSON backup regularly. Clearing browser/site data, losing the device, or switching browsers can remove local records. Import your JSON backup to restore them on another device.

## Existing Steady Week data
This build attempts a basic migration from a few common older local-storage keys, but the exact previous build's storage format is not available in this package. If you have an older JSON backup, use Settings > Import backup. Export a backup from the old app before replacing it whenever possible. Do not overwrite your existing hosted app until you have exported its data.
